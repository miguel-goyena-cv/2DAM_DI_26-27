## 🚀 Cómo ejecutar los proyectos
1. Clona este repositorio:
   ```bash
   git clone https://github.com/miguel-goyena-cv/2DAM_DI_26-27.git
   ```
2. Poner esta carpeta donde se quiera y yo suelo trabajar con VSCode.
3. Para SCSS: Ejecutar el comando sass XXXXX antes de abrir la página principal.
4. Para TS: Ejecutar el comando tsc para compilar los fichero TS en JS
5. Para Angular: Ejecutar un ng serve en el terminal. Previamente npm install para las dependencias
5. Para Ionic: Ejecutar un ionic serve en el terminal. Previamente npm install para las dependencias
